# Workstation — 验证方式

本仓库采用本机桌面手动验收，不以自动化测试验收。完整框架检查见 ../../Core/Framework/testing.md。本轮第 1 项已获验收，第 2–4 项完成后统一验证。

```powershell
dotnet run --project Launcher/Launcher.csproj -c Debug
```

1. 启动台结束后主页、菜单、状态栏完整出现；Ctrl+P 和面板快捷键可用，设置入口和“回到主页”正常。
2. 打开设置页，调整三个面板的显隐、尺寸和四档对齐，再重置布局。设置页保持，默认布局恢复；回主页后再开设置正常。
3. 改布局后退出重进，恢复显隐/尺寸/对齐；刚修改即退出也保存。重置后等待超过 500ms，不应被旧写入恢复原布局。
4. 修改语言出现重启提示，改回启动值提示消失；立即重启后语言生效，布局保存。设置页分组和编辑器使用同一有效声明。
5. 当前没有内置工具视图。临时提供 ActivityBar/AuxiliaryPanel 工具视图后，跨三个 Bar 移动、向隐藏面板投放、拖空源面板、同 Bar 重排、四档对齐下重置：默认归属恢复、活动项正确、缓存内容不丢、没有“已有父级”异常，空面板没有残留内容。

一次性诊断已通过重置主视图 ID/对象一致、空宿主清理、跨区移动/重置期间对象宿主唯一和配置往返顺序；诊断没有真实可视树，拖拽、焦点、边距与窗口效果仍需目验。

其他受影响的常用路径：主页模块树刷新清空选择与说明；文件菜单退出、帮助关于；macOS 原生菜单与其他平台标题栏菜单；命令面板过滤、上下导航、Enter/Esc、快捷键标签。按实际修改平台检查，不把编译成功视为 UI 已验收。
